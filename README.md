# davidherel.com

Source of [davidherel.com](https://davidherel.com), a one-page CV served by GitHub Pages from `main` (see `CNAME`).

- `index.html` — the whole site. Edit the text here.
- `css/style.css` — screen styles. After changing it, bump the `?v=` query on the stylesheet link in `index.html`.
- `css/print.css` — print layout (two columns, no photo or icons).
- `images/` — photo, logos and thumbnails referenced from `index.html`.
- `404.html`, `favicon.svg`/`favicon.png`, `apple-touch-icon.png`.

No build step. Page views are counted by GoatCounter (`davidherel.goatcounter.com`).
